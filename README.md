# Scouty per Mac con Homebrew

```
brew install --cask scouty-project/scouty/scouty
```

Aggiornare: `brew upgrade --cask scouty` (l'app si aggiorna anche da sola). Il cask scarica da https://scoutyapp.it/download/desktop/.
Questo repository contiene solo il cask, nessun codice dell'app; lo aggiorna `scripts/pubblica.sh` di scouty-desktop a ogni versione.
